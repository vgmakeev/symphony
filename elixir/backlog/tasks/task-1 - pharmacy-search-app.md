## Description

Разработать React-приложение (Vite + TypeScript) с использованием shadcn/ui, реализующее поисковый интерфейс аптечного e-commerce.

## Требования

### Поиск и автодополнение

- Поисковое поле с иконкой поиска, placeholder "Поиск лекарств и товаров..."
- Автодополнение (suggestions dropdown) появляется при вводе от 2 символов
- Debounce 300ms перед запросом
- Подсказки показывают название препарата, форму выпуска и цену
- Поддержка навигации по подсказкам клавиатурой (стрелки + Enter)
- Поиск работает на русском языке

### Страница результатов

- Карточки товаров в grid-сетке (responsive: 1/2/3/4 колонки)
- Каждая карточка содержит: изображение (placeholder), название, производитель, форма выпуска, дозировка, цена, кнопка "В корзину"
- Бейдж "Рецептурный" для рецептурных препаратов
- Сортировка: по цене (возр/убыв), по названию, по популярности
- Количество найденных результатов

### Мок-бэкенд

Реалистичный мок с задержкой 200-500ms, содержащий минимум 30 препаратов на русском языке. Примеры:

- Парацетамол таблетки 500мг №20 — 45₽
- Нурофен Экспресс капсулы 200мг №10 — 189₽
- Амоксициллин капсулы 500мг №16 — 120₽ (рецептурный)
- Лоратадин таблетки 10мг №10 — 35₽
- Эссенциале Форте Н капсулы 300мг №30 — 680₽
- Мезим Форте таблетки №20 — 95₽
- И т.д.

Мок должен поддерживать fuzzy-поиск по названию, производителю и категории.

### Технологии

- React 18+ с TypeScript
- Vite
- shadcn/ui (Button, Input, Card, Badge, Command/Combobox, Skeleton)
- Tailwind CSS
- React Query (TanStack Query) для запросов к моку

- [ ] Выбор подсказки или нажатие Enter показывает результаты
- [ ] Карточки товаров отображаются корректно с ценами в рублях
- [ ] Сортировка работает
