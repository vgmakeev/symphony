## Description

Создать Python-скрипт `fibonacci.py` в корне workspace, который:

1. Принимает число N из аргументов командной строки (по умолчанию N=10)
2. Выводит первые N чисел Фибоначчи
3. Выводит сумму этих чисел

## Acceptance Criteria

- [ ] Файл `fibonacci.py` создан
- [ ] `python3 fibonacci.py` выводит первые 10 чисел Фибоначчи
- [ ] `python3 fibonacci.py 20` выводит первые 20 чисел
- [ ] Скрипт запускается без ошибок
